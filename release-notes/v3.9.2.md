## What's changed

- Fixed the Desktop installer's driver-install and uninstall-cleanup steps pointing to the wrong app filename, which could cause those steps to be skipped.
- Added more useful connection diagnostics in Desktop and Lite, including relay authentication failures, missing return traffic and packet-handling errors.
- Reduced repetitive connection log messages during long or failing sessions.
- Lite logs now include full timestamps to make support reports easier to investigate.

Release: https://github.com/Swift-tunnel/swifttunnel-app/releases/tag/v3.9.2
