## What's changed

- Added a Games library with favourites, rejoin, game shortcuts and up to four recent games. Places from the same experience now share one card.
- Added Matchmaker and a public-server browser to search by Roblox datacenter, with preferred locations and games you can exclude.
- Games can launch the installed Roblox player directly and prepare the matching SwiftTunnel relay before joining a selected location.
- Added per-game FPS, graphics and window settings. Game overrides take priority while playing; previous settings return when Roblox closes.
- Added Roblox VNG launching from Games.
- Added a dedicated FastFlags editor with supported-flag validation, search and simpler controls, plus NVIDIA profile controls for compatible systems.
- Import supported settings from other Roblox launchers through Settings, with a preview before applying them.
- Regional network-ping estimates now load before connecting. The connected relay's number is shown, such as Mumbai 05, and tooltips explain the difference between relay ping and estimated game ping.
- Improved the overlay and renamed In-Game to Overlay, with fixes for positioning, stale readings and session timers.
- SwiftTunnel stays connected when Roblox closes. Session ping statistics pause while Roblox is closed and resume when it opens.
- Removed Auto RAM Clean and reduced repeated background work. Fixed several sources of freezes during startup, connecting and saving settings.
- Improved sign-in, update downloads, installer-cache recovery and interrupted settings recovery across Desktop and Lite.
- Fixed country-ban hosts-file handling on PCs where Windows is installed on a drive other than C:.
