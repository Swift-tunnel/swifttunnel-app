## What's changed

- New Games page: your Roblox games in one place, with favourites, rejoin, shortcuts and the last four you played. Places from the same experience share one card.
- SwiftTunnel can launch Roblox for you and connect the right relay first, so you join the location you picked.
- Matchmaker and a public server browser let you pick a Roblox datacenter, keep a preferred location, and skip games you do not want.
- Per-game FPS, graphics and window settings. A game's own settings win while you play, and your normal settings come back when Roblox closes.
- SwiftTunnel now stays connected when Roblox closes.
- New FastFlags editor with search, validation of supported flags and plain controls, plus NVIDIA profile settings on compatible PCs.

### Games

- Roblox VNG can be launched from Games.
- Import supported settings from another Roblox launcher in Settings, with a preview before anything is applied.
- Launch progress names the city you asked for, and bypassing your preferred location is now its own option, Play in any location.
- Server searches stay bounded, and a server you picked yourself stays picked while SwiftTunnel connects.

### Connect

- Regional ping estimates now load before you connect instead of after.
- The relay you are on shows its number, such as Mumbai 05, in the top line, the route diagram and the via text.
- Tooltips separate relay ping from the estimated game ping, so one number no longer stands for both.
- Session ping statistics pause while Roblox is closed and resume when it opens. Paused time is left out of jitter.

### Roblox and the overlay

- In-Game is now called Overlay, with fixes for positioning, stale readings and session timers.
- Your global Roblox settings survive a temporary game profile, and FastFlag values are written in the form Roblox expects.
- An interrupted settings save no longer blocks the Games library or launching.

### Setup and updates

- Updates no longer fail when another program has changed the owner or permissions of SwiftTunnel's installer folder. SwiftTunnel uses a separate protected folder instead of weakening anything.
- Update downloads, installer preparation and driver installs now have time limits, so a stuck step reports an error instead of hanging.
- Changing your update channel discards an offer from the old one.
- Release downloads now carry a build attestation, so anyone can check that a file came from our own build.

### SwiftTunnel Lite

- The tray icon comes back when Windows restarts the taskbar.
- Pasting a password keeps the spaces you pasted.
- Lite disconnects safely before repairing the driver or handing over an update.
- Settings writes no longer overwrite each other, and Roblox edits are written once the player closes.

### Fixes

- Fixed the country-ban bypass on PCs where Windows is not installed on the C: drive.
- Removed Auto RAM Clean and the obsolete network offload controls.
- Sign-in recovers from a cancelled or stalled browser sign-in, and a saved login survives a failed refresh.
- Diagnostics can be stopped and still report what they found.
- Less background work while connected: fewer repeated scans, less idle polling, and lighter settings and graph screens.
- Many more small fixes.
