## What's changed

- Less stutter while gaming. The connection graph re-done.
- Free time no longer cuts you off mid-match. You get a short grace window, and
  the timer counts down the extra time before disconnecting.
- SwiftTunnel no longer offers other VPN adapters.
- Driver install failures now point at Repair, then "Reinstall driver", instead
  of asking you to restart Windows.

**This update is required.** Older versions can no longer connect.

Release: https://github.com/Swift-tunnel/swifttunnel-app/releases/tag/v3.0.4
