## What's changed

A reliability release: steadier game routing, faster connects, and cleanup and repair that put Windows back the way they found it.

- Game traffic now stays on its relay route under heavy load, instead of sometimes slipping to a direct path mid-game.
- Fixed a packet-worker wake-up issue that could interrupt traffic.
- Connecting is faster: fewer network-driver checks, and Windows settings are read directly instead of starting PowerShell.
- Signing out now disconnects first, and keeps your Auto-reconnect choice.
- Repair checks that its cleanup really worked and tells you what is left, instead of reporting success.
- Quitting waits for a running connect, repair or boost to finish before restoring your settings.
- Less background work while you play or when the window is hidden.

### Connection and routing

- Game connections keep their route through congestion, retries and relay changes. Ordinary web traffic from other apps stays direct.
- If the network driver stops passing traffic, the connection ends with a clear message instead of silently dropping packets.
- Reconnecting waits for the previous connection to finish stopping, and automatic adapter selection skips adapters that are down.
- Changed how IPv6 is held back while connected. The original setting is recorded so it can be put back.
- Network-boot (diskless) PCs: SwiftTunnel will not connect if it cannot protect the boot connection.
- Disconnect shows completion as soon as local cleanup finishes.
- Recently failed relays stay out of Auto Route during their cooldown, and the relay list recovers better after network failures.
- Lite orders regions by their displayed ping and waits longer between failed automatic reconnects.

### Repair and cleanup

- Reorganized Repair around the problem you are experiencing, with clearer guidance before actions that disconnect you.
- Your own hosts-file entries are left alone during cleanup, and a damaged SwiftTunnel block is repaired when it only holds SwiftTunnel's entries.
- A partly finished network restore is saved and retried on the next start.
- Cleanup no longer resets shared network settings while the other SwiftTunnel app (Desktop or Lite) is running.

### Updates, setup and uninstall

- Stable update checks can recover when GitHub's release API refuses the request. Update signatures are still verified.
- Removed duplicate startup update checks and fixed update states that could block retries or lose a pending restart.
- Improved recovery when Windows Installer records or installation files are missing.
- Fixed uninstall cleanup starting another Windows Installer operation inside an active uninstall.
- Improved driver repair on non-English Windows and recovery for blocked WebView2 data folders.

### Games, FastFlags and overlay

- Fixed old Roblox log entries being mistaken for a new join and favourites being lost when game metadata changes.
- Custom FastFlag imports are checked before Lite switches that mode on, and a draft that cannot be read is kept instead of discarded.
- Refreshed pop-ups and the FastFlag forms. Game artwork falls back to a replacement image when a thumbnail fails.
- Lite preserves intermediate Roblox graphics levels when changing other settings, such as the FPS cap.
- Improved overlay click-through, stale-display handling and background stats collection.

### Optimizations and diagnostics

- Preserved existing power plans, VRR and Auto HDR settings when applying related optimizations.
- Automatic disk cleanup, browser GPU-disable and scheduled drive-optimization-disable stay out of bulk apply.
- Clearer messages that tell a failed relay ping apart from Windows or security software blocking the connection.
- Support logs now include operation timings and useful failure reasons, with fewer repeated messages.
- Error text that contains links is no longer sent for translation.
