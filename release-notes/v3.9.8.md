## What's changed

### Connection and performance

- Fixed a packet-worker wake-up issue that could interrupt traffic, and improved cleanup when a connection ends.
- Reduced background polling, repeated process scans and unnecessary UI updates while playing or when the window is hidden.
- Improved connection startup by avoiding repeated network-driver checks when the adapter is already known to the driver.
- Disconnect now shows completion as soon as local cleanup finishes, while the final session report runs in the background.
- Improved relay-list recovery after network failures and kept recently failed relays out of Auto Route during their cooldown.
- Lite now orders regions by their displayed ping and waits longer between repeated failed automatic reconnects.

### Updates, setup and uninstall

- Stable update checks can recover when GitHub's release API refuses the request. Update signatures are still verified.
- Removed duplicate startup update checks and fixed update states that could block retries or lose a pending restart.
- Improved recovery when Windows Installer records or installation files are missing, while preserving usable installer sources.
- Fixed uninstall cleanup starting another Windows Installer operation inside an active uninstall.
- Improved driver repair on non-English Windows installations and resolved driver paths through Windows' folder locations.
- Added recovery for blocked WebView2 data folders and improved startup and window-close handling.

### Games and overlay

- Fixed old Roblox log entries being mistaken for a new join and favourites being lost when game metadata changes.
- Lite preserves intermediate Roblox graphics levels when changing other settings, such as the FPS cap.
- Improved overlay click-through, stale-display handling, worker shutdown and background stats collection.
- Preserved existing power plans, VRR and Auto HDR settings when applying related optimizations.
- Kept browser GPU-disable and scheduled drive-optimization-disable tweaks out of bulk apply, and corrected misleading tweak descriptions.

### Repair and diagnostics

- Reorganized Repair around the problem you are experiencing, with clearer guidance before actions that disconnect you.
- Added operation timings and useful failure reasons to support logs, including connection, update and installer steps.
- Improved native log copying and log rotation, reduced repeated messages and kept raw scripts out of common error messages.
- Improved speed-test failure handling and prevented bufferbloat grades when the test did not generate enough valid traffic.
