## What's changed

- Fixed "not authorized" when connecting. If your session had expired the app kept you signed in and refused to connect, and the only way out was to log out and back in yourself. It now signs you out and takes you to the sign-in screen, so signing back in fixes it.
- Connecting no longer tries every server in turn when the problem is your session, so it fails fast instead of hanging.
- If a server you pinned is busy, the app tells you and names a quieter one in the same city.
- Busy servers are avoided automatically when picking a relay for you.

Release: https://github.com/Swift-tunnel/swifttunnel-app/releases/tag/v3.0.1
