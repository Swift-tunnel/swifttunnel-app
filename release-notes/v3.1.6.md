## What's changed

- FPS unlock is now on by default.
- New "Reset Roblox to default" button on the Roblox page. It closes Roblox and removes every FFlag on your PC, including ones done by strapper.
- Uninstalling now properly undoes everything SwiftTunnel changed in Roblox. It could previously leave flags and a lowered graphics quality behind.
- Ultraboost now says what it costs: maximum FPS at the lowest detail.
- Fixed connecting failing after 90 seconds on machines where Windows is slow to respond.
- Updates now wait for Windows Installer's result before reporting success, and report cancellation or failure correctly.
- Setup, updates and installer repair now share a protected package cache. Older installer sources are kept for future repair and uninstall.
- Optimizations now save recovery information before changing Windows settings. If applying or restoring a setting fails, recovery information remains available for another revert attempt.
- Connections now request a fresh ticket promptly when a supported relay detects a NAT address change. Ticket requests keep the same identity across network retries.
- Lite release builds now use a fixed update verification key that cannot be replaced through an environment variable.
- Lite now rechecks installer registration immediately before updating, covering cached packages removed while Lite was open.
- Desktop MSI upgrades now attempt recovery when the previous Desktop installer cache is missing, before removing the old version or installing new files.
- Added Windows on ARM recovery Setup packages for Desktop and Lite, for upgrades blocked by a missing older installer.
- Desktop logs now rotate during long sessions, and unchanged adapter selections no longer flood the log when destinations alternate.
- Roblox log detection now tolerates malformed text and waits for partially written lines to finish.
- Slow performance samples no longer queue duplicate requests from different tabs. Adapter listing, optimization status reads and preset exports now run off the UI thread.
- Removed the NVIDIA Profile Inspector integration.
