## What's changed

**Installing over an older version no longer gets stuck.** Windows keeps a copy
of every installer it has run, and upgrades need the old one to remove the old
version. PC cleanup tools delete or truncate that copy, and when it is gone the
install stops on "the feature you are trying to use is on a network resource
that is unavailable", leaving a PC that can neither upgrade nor uninstall.
SwiftTunnel now clears the stale record itself before upgrading, and the same
repair reaches installs it previously walked past: ones where the copy was
damaged rather than deleted, and ones installed for a single user.

**Country ban bypass works on PCs with no hosts file.** Windows does not need
one, so antivirus and cleanup tools remove it without warning, and bypass could
not write the entries it needs. It reported "unavailable on this network", which
sent people to change their DNS when nothing was wrong with their network. The
file is now created when it is missing, the Repair tab checks for it, and the
message says what actually failed.

**SwiftTunnel Lite is a native app.** It was a second browser engine in a small
window; it is now a Windows program of its own. One process instead of seven,
7MB of memory instead of hundreds, and 0.08% of a core while connected and
minimised. Same tunnel, same relays, same account, same free hours.

Lite also gains a proper sign-in screen, custom FFlags imported from a file
rather than pasted, and its own entry in Add/Remove Programs when installed on
its own.

**Fixes**

- Typing in Lite no longer makes the whole window flicker
- Text fields take a caret, selection, and paste
- "Network adapter" is no longer cut off to "Network ad..."
- Connection errors show the advice instead of truncating it
- Lite has an icon in the taskbar and in Explorer
- Rejected FFlags are all listed at once, with the real reason
