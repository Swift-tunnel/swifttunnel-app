## What's changed

- Fixed game and server detection sometimes missing a join after Roblox updates, which could delay game status and join notifications.
- Relay connections now keep their recovery window when Windows reports the device offline, giving brief internet interruptions time to recover before the session ends.
- Automatic relay ping refreshes pause while Roblox is running, reducing background network work. With Roblox closed, readings refresh when you return to the window or open the picker.
