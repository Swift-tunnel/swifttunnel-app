## What's changed

- Desktop and Lite now show estimated game network ping when measurements are available, combining your connection to the relay with the relay's connection toward the game's datacenter. Relay-only ping is labelled separately.
- Automatic relay selection within a region can now compare measured game routes when you join a game. Manually selected relays stay selected.
- Lite now checks every available relay's latency instead of sampling one relay per region.
- Added Windows notifications at 50% and 90% of free time used, plus a warning with 1 minute remaining.

Release: https://github.com/Swift-tunnel/swifttunnel-app/releases/tag/v3.9.3
