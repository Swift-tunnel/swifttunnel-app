## What's changed

- Fixed the free time showing as used up the day after it refilled, which left Connect doing nothing until SwiftTunnel was restarted.
- Fixed an "update required" message that could stay on screen after the problem was over, with the same effect.
- Installs no longer break when a PC cleanup tool deletes Windows' installer files. SwiftTunnel keeps its own copy, so upgrading and uninstalling keep working.
- A stuck install now repairs itself when SwiftTunnel starts, instead of only when you run the setup installer.
- Removing SwiftTunnel or SwiftTunnel Lite no longer stops the other one from connecting or starting with Windows.
- Uninstalling is much faster and no longer sits there looking frozen.

Release: https://github.com/Swift-tunnel/swifttunnel-app/releases/tag/v3.1.2
